# Objective × evaluation budget × actuator saturation study
Independent benchmark. Main, canonical motor model, and prior pilot are untouched.

From repository root (Python 3.13 used):
```
python -m venv .venv-study
.venv-study/bin/pip install -r pilot/objective-budget-torque-20261110/requirements.txt
MPLCONFIGDIR=/tmp/kroc-mpl .venv-study/bin/python pilot/objective-budget-torque-20261110/validate.py
MPLCONFIGDIR=/tmp/kroc-mpl .venv-study/bin/python pilot/objective-budget-torque-20261110/run.py > pilot/objective-budget-torque-20261110/execution.log 2>&1
MPLCONFIGDIR=/tmp/kroc-mpl .venv-study/bin/python pilot/objective-budget-torque-20261110/analyze.py
```
Full actual environment: environment-freeze.txt. Read PROTOCOL.md before interpreting results. Initial compile failure is retained; it occurred before any candidate simulations and was fixed without changing scientific conditions. All later numerical failures, if any, stay in candidate archive. Candidate count includes duplicates and failed candidates; no uncounted replacement trials.

Statistical intervals concern optimizer seed variability, not sensor noise, hardware variation, or population of robots. Test trajectories are not independent optimizer replications. No hardware performance or energy-saving claims.

Completed results and Korean recommendation: `results/REPORT_KO.md` (generated by build_report.py plus VERDICT_KO.md). Figures: budget_rmse.png, interaction.png, final_ranking.png, trace.png. `final_plot.py` regenerates final_ranking.png.

Post-result exploratory diagnostics are separate: `posthoc_diagnostics.py` evaluates fixed final gains under crossed training/deployment torque limits and derivative-on-reference weighting 0/1. Run after run.py. It performs no optimization and never overwrites main candidate/selected metrics. This optional simulator argument was added after inspecting the main outcomes; its default is still zero. All 80 original final smooth-condition metrics were checked to match at 1e-13 tolerance. These diagnostics are not part of the frozen confirmatory design.

Main execution: 88,064 candidate evaluations (104 GA runs), 1,416 checkpoint rollouts, 160 refinement baseline repeats, 320 refined rollouts, 2 trace rollouts = 89,962 simulator calls. Separate posthoc diagnostics add 320 calls; paper gain sanity adds 12. Numerical model checks and their reruns are separate. Main wall time 1,908.28 seconds (31.80 min), as directly measured, not inferred by summing rounded per-arm timings. Machine scheduling/pauses and final output are included in wall time. No hardware or GitHub Actions execution is claimed.

Critical result: ISE/IAE ranking reverses on the held-out smooth trajectory in all ten final confirmatory seeds, but the crossover audit attributes much of this to gains learned under constrained step tuning, rather than direct deployment clipping. A universal objective recommendation is not supported. Gain-bound and training-trajectory sensitivity remain unexecuted.
